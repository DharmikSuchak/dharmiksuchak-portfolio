# Dharmik Suchak — Software Engineering Portfolio

This is the personal portfolio of Dharmik Suchak, a Software Engineer specializing in backend systems, full-stack development, and AI/LLM applications.

## 🚀 Features

- **Modern Tech Stack**: Built with React, Vite, and modern JavaScript (ES6+).
- **High-Performance**: Optimized for fast loading speeds and smooth interactions using Framer Motion.
- **Responsive Design**: Flawless experience across desktop, tablet, and mobile devices.
- **SEO Optimized**: Includes meta tags, OpenGraph data, and semantic HTML for search engine visibility.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DharmikSuchak/dharmiksuchak-portfolio.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd portfolio-app
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```

## 📜 Scripts

- `npm run dev` - Starts the Vite development server.
- `npm run build` - Builds the application for production.
- `npm run preview` - Previews the production build locally.
- `npm run lint` - Runs Oxlint to analyze the code for issues.
